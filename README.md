  <h2>1. HTML Gives a Web Page Structure</h2>

  <p>
            One of the biggest things I have learned about HTML is that it gives a
            webpage its basic structure. HTML stands for HyperText Markup Language,
            and it uses elements to tell a browser what different pieces of content
            are. Instead of just putting words on a blank page, HTML allows you to
            organize those words into headings, paragraphs, lists, links, images,
            and other elements.
      </p>

  <p>
            For example, using <strong>&lt;h1&gt;</strong> creates a main heading,
            while <strong>&lt;p&gt;</strong> creates a paragraph. Lists can be
            created with <strong>&lt;ul&gt;</strong> and <strong>&lt;li&gt;</strong>.
            These elements make the content easier for both people and browsers to
            understand.
      </p>
My biggest takeaway is that HTML is about organization and structure, not just making a webpage look good.
  </p>
   </section>

<h2> HTML and CSS Work Together <h2>

  <p>
            Another important takeaway is that HTML and CSS have different jobs,
            but they work especially well together. HTML creates the structure and
            content of a page, while CSS controls how that content looks. CSS can
            change colors, fonts, spacing, borders, backgrounds, and the overall
            appearance of a webpage.
        </p>

  <p>
            For this project, I used CSS to change the background color, text color,
            spacing, and appearance of my sections. I also added a colored border
            to each takeaway to make the different sections easier to identify.
            These small changes show how CSS can make a basic HTML document much
            more visually interesting.
        </p>

  <p>
            Some simple CSS choices I can use include:
    </p>

  <ul>
            <li>Changing the background color</li>
            <li>Changing the font or text color</li>
            <li>Adding borders and spacing</li>
            <li>Changing the size of headings</li>
            <li>Creating different sections on a page</li>
        </ul>
    </section>

   <h2>3. HTML Can Be Useful for Technical Writers</h2>

  <p>
            The third takeaway I have is that HTML can be especially useful for
            technical writers. Technical writers often create instructions,
            documentation, help pages, tutorials, and online resources. HTML gives
            writers a way to organize this information so that readers can easily
            navigate and understand it.
      </p>

  <p>
            I also think HTML is useful because it gives technical writers more
            control over how information is presented online. For example, a
            technical writer could use headings to organize a long tutorial, lists
            to explain steps, links to connect readers to additional information,
            and CSS to make important warnings or instructions stand out.
        </p>

  <p>
            Learning HTML also connects to other tools that technical writers use,
            such as Markdown and GitHub. While Markdown is often quicker and simpler
            for creating formatted text, HTML provides more control over the
            structure and appearance of a webpage.
        </p>
